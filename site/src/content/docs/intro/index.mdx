inside purrTTY, and sees the simulation as `/sim`. You can poke at it with shell tools, write a
flight computer, run a dashboard, or hand a local AI agent a properly shaped API.

## The short version

The game publishes live snapshots. `/sim`, HTTP, MQTT, serial, and MCP project that shared model in
different forms. Control requests go back through one game-thread command path. That is why a shell
script and a host dashboard can agree about the same vessel instead of getting into a small custody
dispute.

The rest of Intro explains the friendly mental model. The [Reference](/gatOS/reference/) is where
the exact paths, units, limits, command phases, and error codes live.
