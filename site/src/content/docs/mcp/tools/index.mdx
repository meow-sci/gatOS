Every tool returns structured content. Read the [shared conventions](/gatOS/mcp/conventions/) for
freshness, envelopes, pagination, phases, and errors.

## World and discovery

| Tool | Purpose |
|---|---|
| [`gatos.get_world`](/gatOS/mcp/tools/get-world/) | Current world summary or complete snapshot |
| [`gatos.get_runtime_state`](/gatOS/mcp/tools/get-runtime-state/) | Complete state for one feature store/runtime |
| [`gatos.get_capabilities`](/gatOS/mcp/tools/get-capabilities/) | Actions, schemas, units, phases, gates, limits, and safety |
| [`gatos.wait`](/gatOS/mcp/tools/wait/) | Wait for snapshot, event, or UT progress |

## Celestials, vessels, and kittens

| Tool | Purpose |
|---|---|

| [`gatos.get_vessel`](/gatOS/mcp/tools/get-vessel/) | Selected complete vessel sections |
| [`gatos.list_kittens`](/gatOS/mcp/tools/list-kittens/) | EVA kitten discovery |
| [`gatos.get_kitten`](/gatOS/mcp/tools/get-kitten/) | Kitten-validated vessel document |

|---|---|

|---|---|
| [`gatos.vessel_control`](/gatOS/mcp/tools/vessel-control/) | Whole-vessel flight, focus, and visual state |

| [`gatos.camera_track`](/gatOS/mcp/tools/camera-track/) | Camera-track store and player |
