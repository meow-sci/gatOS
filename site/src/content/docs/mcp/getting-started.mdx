gatOS hosts MCP inside the C# game mod. There is no stdio proxy, guest endpoint, bearer token, or
remote listener in v1.

## Endpoint and configuration

The default endpoint is:

```text
http://127.0.0.1:4243/mcp
```

The listener is enabled by default. In `gatos.toml`:

```toml
mcp_enabled = true
mcp_preferred_port = 4243
```

Set the preferred port to `0` to request an ephemeral port. A nonzero port is clamped to
`1024..65535`; if it is occupied, gatOS falls back to an ephemeral port. Read the actual port from
the gatOS status window or transport status surfaces.

## Transport behavior

- Streamable HTTP at `POST /mcp` on `127.0.0.1` only.
- Stateless request handling: no `Mcp-Session-Id`, GET event stream, DELETE, legacy `/sse`, or `/message` endpoint.
- Exact local `Host` validation. `Origin` may be absent for native clients; when present it must be an exact local origin.
- No CORS response headers and no bearer token.
- Each POST stays open until its handler completes, so command and wait calls preserve request-level backpressure.
- Current discovery and compatible initialize-capable clients are handled by the official C# MCP SDK.

## First agent sequence

<Steps>
  1. Connect your Streamable HTTP MCP client to the actual bound endpoint. 2. Call
  [`gatos.get_capabilities`](/gatOS/mcp/tools/get-capabilities/) and retain its gates, limits,
  phases, and action metadata. 3. Call [`gatos.get_world`](/gatOS/mcp/tools/get-world/) with
  `detail:"summary"`. 4. Discover a target with
  [`gatos.list_vessels`](/gatOS/mcp/tools/list-vessels/) and read it with
  [`gatos.get_vessel`](/gatOS/mcp/tools/get-vessel/). 5. Confirm `controllable`, the target raw id,
  its current parent, and any relevant feature gates. 6. Submit one narrow logical action, such as
  [`gatos.ignite_engines`](/gatOS/mcp/tools/ignite-engines/) or
  [`gatos.vessel_control`](/gatOS/mcp/tools/vessel-control/). 7. Call
  [`gatos.wait`](/gatOS/mcp/tools/wait/) with the previous `snapshot_sequence`, then re-read state
  before planning again.
</Steps>

## A minimal interaction

```text
gatos.get_capabilities({})
gatos.get_world({ "detail": "summary" })
gatos.get_vessel({ "id": "active", "include": ["flight", "propulsion", "resources"] })
gatos.vessel_control({ "operation": "throttle", "vessel_id": "Hunter", "value": 0.35 })
gatos.ignite_engines({ "vessel_id": "Hunter" })
gatos.wait({ "after_sequence": 812, "timeout_ms": 30000 })
```

These examples show tool names and JSON arguments, not a vendor-specific client library syntax.
Your MCP client supplies the JSON-RPC and HTTP framing.

## Shutdown and cancellation

Closing a request cancels cancellable handlers such as `gatos.wait`. A command cancelled before it
is admitted to the game-thread queue is abandoned. Once the game thread begins executing a command,
the action is not reversible. Mod shutdown cancels active requests and disposes the listener before
the shared stores.
